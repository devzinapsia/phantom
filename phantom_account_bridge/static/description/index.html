Phantom Account Bridge

Create real invoices, receipts and reconciliations from Phantom staging data

Turns the invoices and receipts imported by phantom_connector into real Argentine account.move and account.payment records, matching customers by CUIT/DNI, applying the right VAT per item, and reconciling payments against their associated invoice automatically.

Key Features

  • Correct AR document types: Factura/NC/ND mapped to the right move_type and l10n_latam document type, letter included.
  • Per-item VAT: each Detalle item's tax percentage is matched to a real sale tax, not ignored.
  • Safe customer matching: by identification type + number, reusing existing contacts without ever overwriting them.
  • Automatic reconciliation: a receipt linked to an invoice gets reconciled as soon as both exist, retried across runs if needed.
  • Full traceability: smart buttons in both directions, staging record to document and back.
