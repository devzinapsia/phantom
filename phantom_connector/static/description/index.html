Phantom Connector

Import invoices and receipts from the Phantom billing/collections system

Connects to Phantom's REST API, per company, and keeps a local staging copy of every invoice, credit note, debit note and payment receipt it reports. Nothing is transformed into a real accounting document here -- that is the job of the separate phantom_account_bridge module, if installed.

Key Features

  • Per-company credentials: each company can point at its own Phantom instance.
  • Manual or automatic: trigger imports by hand, or schedule a daily run at a configured local time.
  • Rolling sweep window: every run re-queries the last N days, to catch vouchers Phantom loaded late.
  • Safe upsert: re-importing the same voucher updates it in place and never reopens one already processed into a real document.
  • Built-in dashboard: import volume, pending backlog, and last successful run, at a glance.
